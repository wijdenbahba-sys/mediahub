# MediaHub

## Présentation

MediaHub est une application web développée avec Laravel dans le cadre d’un projet d’apprentissage.

## Objectif

L’objectif de MediaHub est de mettre en place une application web permettant de découvrir, organiser et gérer des contenus multimédias de manière simple et intuitive.

Ce projet permet également de mettre en pratique les concepts de Laravel, notamment les routes, les contrôleurs, les vues et la gestion des données.

## Technologies utilisées

* Laravel
* PHP
* HTML
* CSS
* JavaScript
